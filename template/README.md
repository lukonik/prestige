# Prestigia documentation site

This project was created with `@prestigia/cli`. It combines TanStack Start,
Tailwind CSS, Shadcn components backed by Base UI, and Content Collections.
Prestigia merges `prestigia.config.ts` navigation with the generated `allDocs`
collection and prerenders the documentation site at build time; no content
server functions or runtime SSR are required.

```sh
pnpm install
pnpm dev
```

Author Markdown documents in `content/docs` and configure their sidebar order,
groups, links, or autogenerated directories in `prestigia.config.ts`. Add
Shadcn components with:

```sh
pnpm shadcn add card
```
